# Sicherheitsrichtlinie

## Supported Versions

| Version | Unterstützt |
|---------|-------------|
| main    | Ja          |
| < 0.1   | Nein        |

## Sicherheitslücken melden

Bitte NICHT als öffentliches Issue melden.

Stattdessen:
- E-Mail an den Maintainer (siehe GitHub-Profil)
- Oder: GitHub Security Advisory (privater Report)

Wir antworten innerhalb von 72 Stunden.

## Was wir als Sicherheitslücke betrachten

- Proxy-Bypass (Traffic außerhalb I2P)
- DNS-Leaks
- WebRTC-Leaks
- Fingerprint-Leaks trotz Härtung
- Code-Injection
- Sandbox-Escape

## Was KEINE Sicherheitslücke ist

- I2P selbst ist langsam (bekannt)
- Bestimmte Webseiten funktionieren nicht über I2P
- Fehlende Features
